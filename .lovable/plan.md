# لوحة "تسجيل الدخول" السفلية

عند الضغط على زر "دخول" في أعلى قائمة الغرف، تنزلق لوحة بيضاء من أسفل الشاشة وتغمق الصفحة خلفها مع تصغيرها قليلاً — طبق الأصل للصورتين.

## السلوك

- خلفية سوداء شبه شفافة تغطي الصفحة، وقائمة الغرف تتقلص قليلاً (scale ~0.94) مع حواف دائرية.
- اللوحة تنزلق للأعلى بحركة سلسة (~300ms)، وفي أعلاها مقبض رمادي صغير.
- الإغلاق بالضغط على الخلفية أو سحب اللوحة للأسفل، مع نفس الحركة بالعكس.

## محتوى اللوحة

عنوان "تسجيل الدخول" بخط عريض كبير، ثم مفتاح تبديل أزرق "دخول كزائر/ة":

- **زائر (المفتاح مُفعّل):** حقل "الأسم المستعار" بأيقونة شخص + قائمة "النوع" (ذكر/أنثى) بأيقونة M/F + زر "دخول" أزرق عريض.
- **عضوية (المفتاح مُطفأ):** حقل "الأسم المستعار" + حقل "الرقم السري" بأيقونة قفل + زر "دخول" أزرق، ثم "نسيت كلمة السر؟" مع زر "استعادة كلمة السر" بخلفية زرقاء فاتحة.

أسفل الاثنين: "لا يوجد لديك عضوية؟" مع زر "إنشاء حساب مجاناً" (خلفية زرقاء فاتحة، نص أزرق)، ثم سطر "الرجاء قراءة شروط الاستخدام - و قراءة سياسة الخصوصية" بروابط زرقاء.

## النطاق

هذه المرحلة واجهة فقط: الدخول كزائر يحفظ الاسم المستعار والنوع محلياً (نفس المفتاح المستخدم حالياً في صفحة الغرفة) ويُغلق اللوحة. زر العضوية وإنشاء الحساب واستعادة كلمة السر تعرض رسالة "قريباً" حتى نفعّل الحسابات الحقيقية لاحقاً.

## تفاصيل تقنية

- مكوّن جديد `src/components/LoginSheet.tsx` + حالة فتح/إغلاق في `src/routes/index.tsx`.
- ألوان جديدة كـ tokens في `src/styles.css`: أزرق الأزرار (#0a7cff تقريباً)، الأزرق الفاتح للخلفيات، لون طبقة التعتيم.
- الحركة عبر CSS transitions (translate-y + scale) بدون مكتبات إضافية.
